What was exercised

Integration, not mocks

Testcontainers starts Postgres 16, Flyway applies the real migrations, and the tests drive the running server over HTTP — including the partial unique index that makes idempotency safe.

One domain, two transports

REST and GraphQL share services and repositories. Errors do not: REST returns RFC 9457 problem details, GraphQL returns typed errors with a code.

Seed data uses fixed UUIDs and prices, so the recordings below are reproducible rather than incidental.

Design decisions

  • JDBC over JPA — explicit SQL, no lazy-loading surprises, and it pairs with the migration lab.
  • REST and GraphQL together — one service layer, two contracts, two error shapes.
  • Idempotency keys — a partial unique index, not an application-level lock.
  • Transactional outbox — the event commits with the order or not at all.
